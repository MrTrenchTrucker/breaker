# web-fe — README

**Status:** in progress by the maintainers' team (issue #21). This branch is the module's main PR; it stays open until the module is complete.

The Breaker website, served from its own container on the VPN. Users register and log in, and view, search and copy their transcriptions from any device. Decryption happens in the browser, not on the server. It also hosts the APK and the CA certificate for download, and gives admins a panel for users, the transcription service and agent tokens.

Full module card, including how to run its tests: `AGENTS.md` in this folder.
