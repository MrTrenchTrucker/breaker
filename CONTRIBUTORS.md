# Contributors

Everyone who has contributed to Breaker. Thank you.

**Adding yourself:** in the pull request with your first contribution, add
one line to the end of the list below, in the same format as the first entry:

    - **Name** ([@github-handle](https://github.com/github-handle)) — what you contributed

Use plain words for what you contributed, separated by commas, for example:
architecture, code (a module name), tests, docs, design, review, bug reports,
maintainer. Keep the list in order of first contribution: new names go at the
bottom. Apart from the test paths your module's card names under Test Locations, this
is the only file outside your module that your pull request may touch.
